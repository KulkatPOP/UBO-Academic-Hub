# UBO Academic Hub

UBO Academic Hub es un prototipo de plataforma universitaria diseñada para centralizar la experiencia del estudiante en un único ecosistema digital.

## Problema

Actualmente, los estudiantes deben utilizar múltiples plataformas y canales para consultar información académica, administrativa y universitaria. Esta fragmentación dificulta el acceso oportuno a datos relevantes y hace menos clara la experiencia estudiantil.

La propuesta busca centralizar:

- Información académica.
- Servicios universitarios.
- Vida estudiantil.
- Recursos de apoyo.

## Objetivo

Crear una aplicación universitaria moderna que permita al estudiante gestionar su vida académica desde un solo lugar, con una experiencia móvil, clara e institucional.

## Vista general

UBO Academic Hub permite al estudiante acceder desde una única aplicación a sus principales necesidades universitarias:

- Gestión académica.
- Organización de actividades.
- Servicios institucionales.
- Participación en la vida universitaria.
- Recursos de apoyo.

La aplicación está diseñada como una Progressive Web App (PWA), permitiendo una experiencia similar a una aplicación móvil instalada.

## Arquitectura

La aplicación es un frontend estático basado en HTML, CSS y JavaScript puro. Su estructura está preparada para evolucionar hacia una arquitectura institucional con:

- Backend.
- API.
- Autenticación real.
- Base de datos.
- Roles de usuario.

Actualmente funciona como prototipo frontend con datos simulados.

La arquitectura está preparada para una futura integración con servicios institucionales mediante:

- API backend.
- Sistema de autenticación institucional.
- Base de datos académica.
- Gestión de permisos.
